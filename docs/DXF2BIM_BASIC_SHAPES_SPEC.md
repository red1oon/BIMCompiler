## 3. Shared: rectilinear shell solid
- SH-M `prismRect(outline, holes, z0, z1)`: outline and holes rectilinear (every edge axis-aligned within 1e-9 after rounding to 6 dp), holes inside the outline and disjoint. Grid = all distinct x and y of outline and holes; a cell is solid when its centre is inside the outline and inside no hole. Top and bottom = two triangles per solid cell; sides = one quad (two triangles) per cell edge between a solid cell and a non-solid cell or the outside, oriented outward. Result is one closed, outward mesh (each directed edge once, reverse once). Non-rectilinear input → `GAP:shell_not_rectilinear` (no mesh). Deterministic: cells in (y, x) order.
Tests: SM1 rectangle 2x3, z 0..0.5 → volume 3.0, watertight · SM2 rectangle with a 1x1 hole → volume (6-1) x 0.5, watertight, the hole has inner side faces · SM3 L-shape (area 12) → 12 x thickness · SM4 diagonal outline → gap, no mesh · proves (all): a slab mesh that is open, inside out, fills holes or invents area.

### 4.1 S-O outline (convention on drawn walls)
- S-O Only for a storey whose footprint walls form a rectangular envelope E (bbox of all emitted wall pieces of the plan, rect or polygon). For each face F of E: the exterior pieces of F are pieces whose rect touches F's plane (snap_tol) and whose long axis is parallel to F (squares and polygon corner triangles excluded). Their inner edges (the rect side opposite F) must all be equal within `snap_tol` → inner line of F; zero pieces → `GAP:slab_no_exterior_wall` (face named); unequal → `GAP:slab_inner_face_conflict` (values listed). Outline = rectangle of the four inner lines. Convention, stated: "the slab spans between the inner faces of the exterior walls" (the source model's convention, slab-between-walls); NOT read from a slab entity (none exists in the set). `outline_source: 'exterior_wall_inner_faces'`, `members` = handles used.
- Not drawn, therefore not built: splits of the slab under party walls, stair voids, exterior porch slabs, finish-floor layers. The pipeline cannot see them; the witness lists the area they account for (§4.4).

### 4.2 S-Z top and underside (from elevation-derived wall heights)

- S-Z2 underside U = the common top `level_below + base + height` of the pieces of the storey BELOW that have `height_source: 'elevation'` and end strictly below T (by more than `elev_tol`). All must agree within `elev_tol`, else `GAP:slab_underside_conflict` (values listed); none (no storey below in the set, or no lower piece ends below T) → `GAP:slab_no_underside`. ## 6. Openings cut into walls (drawn gaps bridged)
The Duplex plans split every wall at its openings (drawn gaps). A wall with a window is therefore missing the wall below the sill and above the head. The cut is made by building what the elevation shows around the void, never by guessing it.
- OP-1 Strip: for an opening O (door with a height, or window with sill/height) its host piece H (`host_wall`) gives the strip: H's cross range (rect side across the axis) and axis. Pieces of the same storey with the same orientation and the same cross range (within `snap_tol`) are the strip's pieces, sorted along the axis.
- OP-2 Gap: O's span centre c along the axis (window: bbox centre; door: midpoint of hinge and the swing end point nearer the host axis, SPEC.md M-c) must lie strictly between two consecutive strip pieces A (before) and B (after): G = [A.end, B.start]. c inside a piece → `GAP:opening_inside_piece` (needs a true cut; none expected); no piece on one side → `GAP:opening_gap_unbounded`.
- OP-3 Height: A and B must have the same `level+base` and top within `elev_tol` (else `GAP:gap_height_conflict`) and a height (else `GAP:no_height`). Every opening of G must lie inside [zb, zt] (else `GAP:opening_outside_wall`).
- OP-4 Infill: G x strip x ([zb, zt] minus the union of the z intervals of all openings whose centre is in G) → one box per remaining interval (sill, between stacked windows, lintel), class IfcWall, `infill: true`, `infill_of: [A.handle, B.handle]`, `openings: [handles]`. The void is G x opening z range: its width is the DRAWN gap, not the arc radius.
- OP-5 Gaps without an opening (an interior door with no height, an export-defect door arc, see SPEC.md §21) stay full-height slots and are listed `NOTE:gap_without_opening` with the gap interval.
Tests: OP1 window 1.0 wide, sill 0.9, height 1.2 in a 1.0 gap between two 3 m pieces → 2 infill boxes (0..0.9, 2.1..3.0), total volume = gap x t x (3-1.2) · OP2 three stacked windows → 4 boxes (sill, two mullion strips, lintel), hand z · OP3 door (sill 0) → lintel only · OP4 A and B with different tops → `gap_height_conflict`, no infill · OP5 opening centre inside a piece → `opening_inside_piece` · OP6 gap with no opening → NOTE, no infill · OP7 order independence (20 permutations of ops) · proves: voids not cut, wall above/below a window missing, wall built across a door, invented heights, order dependence.

## 7. Fills from the LOD400 component library (no fallback)
User directive (`~/bim-compiler/prompts/RESUME_MODELLER_LOD400_REAL_GEOMETRY.md` §LOD400-ENVELOPE): a bound product without real geometry is a HARD FAIL plus a GAP; never a box.
- GEO-1 Product → type name. From the bound `ad_opening_family` row: size key = first `NNN x NNN` pair of its description (digits only; same `pairKey` as rosetta_dx_types R-T2); family token = the description text before that pair, trimmed. Candidates = distinct `ad_geometry_map.element_ref` of the same `ifc_class` whose size key equals it; if some candidates' family part (text before the first `:`) equals the token, keep only those. Exactly one → that type; zero → `GAP:no_lod400_geometry`; several → `GAP:lod400_ambiguous`. FROM_LIBRARY_DESCRIPTION (as SPEC.md §40 WALLMAP).
- GEO-2 Geometry: rows of that `element_ref` with their `component_geometries` mesh and `component_definitions` local bbox. Keep the rows whose local long horizontal side lies along the opening's axis (window/door axis X: local X extent ≥ local Y extent). None → `GAP:lod400_orientation`. Several hashes → lowest `geometry_hash` (string order); handing/mirroring is NOT decided (stated). A mesh with ≤ 12 triangles is an envelope → `GAP:lod400_envelope`.
- GEO-3 Placement: translate the local mesh so its bbox centre lands at (cx, cy, cz): window cx, cy = plan bbox centre, door cx, cy = centre of the matched drawn gap G on the strip centreline (OP-2), cz = level + sill + height/2 (door sill 0). No rotation, no scaling (the mesh keeps its authored size). Size delta (mesh bbox vs measured width/height) reported; above `bind.size_tol` → `GAP:fill_size_mismatch` (fill still placed: the product is the bound one).
