Team mode has no central database and no live link. So how do you know its promises hold? Each promise has a test, and the test has a control that must fail when the promise is broken. If the control goes missing, the run fails.

This cut covers the last open promise. Mail between a station and head office is now sealed to that pair, and a member running a modified app opens none of it. What is still not proven: nobody has run the checks from a fresh copy on another machine yet. The relay still sees who sent how much, and when. Not tried on the GitHub relay or with very large teams. Older and office teams are unchanged.
