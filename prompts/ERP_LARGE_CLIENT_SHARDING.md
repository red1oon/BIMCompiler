## Gotchas that cost time this lane
- `pkill -f <name>` inside a Bash call whose command line contains `<name>` kills the calling shell (exit 144) — use `kill <pid>`.
- A blocking `execSync` RSS sampler in the same Node process as the HTTP server starved the server (hung run) — sample with one async `ps`.
- CDP page network throttling does NOT cover dedicated-worker fetches (httpvfs) — shape on the server side.
- Python-injected JS: a `\\n` inside a `//` comment swallowed the next code line — re-read generated lines.
- `.gitignore`: `*.log` and `logs/` are ignored; `docs/internal/*` ignores everything except top-level `*.md` — evidence goes under `prompts/evidence/` as `*.log.txt`.
- PG `pg_dump` snapshot is the only way to freeze a DB with a live writer (`CREATE DATABASE … TEMPLATE` refuses with open connections).
- Unconstrained PG `numeric` (2,957 columns) can hold >17 significant digits; SQLite NUMERIC keeps only 15 → always run the fidelity check after a migration.
- PROGRESS.md is 235 lines (budget 80) — not compacted here because the entries are other lanes' live pointers; compact in a dedicated pass.
