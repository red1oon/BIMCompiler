**I-12 Clearing / control accounts.** AR/AP control, payment clearing (BankInTransit/Unallocated), Unearned, NotInvoicedReceipts/Receivables, Tax Due/Credit, Realized G/L are resolved from `C_AcctSchema_Default` / per-object `_Acct` rows of **that schema**; a clearing account nets to 0 when the cycle closes (shipment+invoice, payment+allocation). **I-13 Multi-tenant isolation.** No row of tenant A is offered (lookup/picker), read (report, TB, open items, aging, doc-no preview), modified (process, import, costing, posting) or numbered by tenant B's session. ## §EXPORTSAFE-SPEC (2026-11-11) — census risk #5 (UDF / TEMP-object loss on `db.export()`), spec BEFORE code
