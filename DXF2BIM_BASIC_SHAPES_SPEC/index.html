    2. Walls¶

    2.1 F9 polygon footprint (Level-2 mitres)¶

    Supersedes SPEC.md D-1 for this goal (user 2026-10-16: Level-2 mitred walls must be rebuilt); D-1 forbade a bounding box, and F9 does not use one. - F9 config.wall.polygon_footprint: true (opt-in; absent = behaviour unchanged, GAP:wall_footprint_not_rect). In footprint mode a closed outline that is neither a rectangle (F1) nor rectilinear (F6), after dedupe and removal of collinear vertices (within snap_tol), and that is a SIMPLE polygon (no two non-adjacent edges cross) with at least 3 vertices, is emitted as ONE wall: outline = the vertices (metres, CCW), polygon: true, rect = its bounding box, axis along the bbox long side through the bbox centre (F2), thickness = bbox short side, square when equal. F4 (duplicate) and F5 (min_thickness on the bbox short side) apply. Self-crossing → GAP:wall_footprint_not_rect as before. - Polygon pieces take no part in the §46 stub pass (neither voters nor subjects). - Mesh (dxf2mesh.meshFromOps): a wall with outline is a prism of the outline from level+base to level+base+height (existing ear-clip prism). Openings hosted by a polygon wall are not cut there: GAP:opening_in_polygon_wall (the shell path of §6 handles openings in drawn gaps; nothing is silently cut). Tests (test_shell.js): WP1 mitred trapezoid (0,0),(4675,0),(4675,417),(417,417) mm → one polygon wall, outline equals input in m, rect (0,0,4.675,0.417), thickness 0.417 · proves: mitres dropped or bbox-filled · WP2 flag absent → GAP:wall_footprint_not_rect · proves: hidden behaviour change · WP3 self-crossing (bow-tie) → gap · proves: invalid outline accepted · WP4 prism volume = shoelace area x height, watertight, outward · proves: polygon mesh wrong · WP5 rectangle and rectilinear outlines unchanged (same ops as without the flag) · proves: F9 hijacks F1/F6.

    2.2 F5b min_thickness after orientation¶

    • F5b When §46 stub orientation is active (opening.gap_max given), wall.min_thickness is checked on the thickness AFTER orientation: a piece below it on its short side is kept as a candidate (not a voter); if a vote turns it so the long side is its thickness, it is emitted; otherwise GAP:wall_below_min_thickness exactly as before. Without gap_max nothing changes (F5). Tests: WT1 pier 20 x 124 mm between a wall piece and a gap (same strip, gap 0.762 m ≤ gap_max) → emitted, thickness 0.124, horizontal · proves: real piers dropped as "thin strips" · WT2 thin strip 800 x 19 mm with no voter → still GAP:wall_below_min_thickness · proves: min_thickness disabled · WT3 thin candidate does not vote for another piece · proves: dropped strips steering orientation.

    2.3 Heights (existing §28 H1-H6) and W-H3 slab-above convention¶

    • Elevation heights per SPEC.md §28 (unchanged). The plan @LEVEL markings (0, 3.1) were set FROM_SOURCE_MODEL by mark_dx_set.js; here each is accepted only if an elevation wall rect of the set has z0 equal to it within elev_tol, OR a drawn level datum line of an elevation lies at it within elev_tol (check LV, drawing-corroborated; the datum clause is §L1.27, 2026-10-17: a building whose walls start below their storey level, e.g. SampleCastle at -0.09 m, still draws every level), else the run stops. A datum states that the level exists, NOT a wall base: wall heights still come from rects that start at the level or from @WALLTOP (with its optional base). The top of the top storey is the highest rect top at its level, else the lowest drawn datum above it; none -> the run stops (no drawn level above the top storey). Implementation: bim-ootb modeller/dxf2bim_import.js (the Modeller's pipeline port); the Duplex Node pipeline (rosetta_dx_shell.js) is unchanged because every Duplex level has a rect.
    • W-H3 (convention, labelled, own height_source): a plan wall piece left GAP:no_elevation_height by H4 takes base 0, height = U - level, height_source: 'slab_above', where U = the underside z of the slab directly above this storey (§4.2 for a floor, §5.2 roof bottom for the top storey). No U → the gap stays. Stated convention (Revit-style "top constraint = underside of floor above"), not a reading of that wall; reported separately from elevation heights. Tests: WH1 unseen piece with U given → base 0, height U-level, source slab_above · proves: convention silently used without label or with the wrong storey · WH2 no U → gap kept, wall dropped · proves: default invented · WH3 a piece with an elevation height is untouched · proves: convention overrides a drawn value.

    2.4 Rosetta wall checks (in rosetta_dx.js and rosetta_dx_shell.js)¶

    • R1b-u (restates SPEC.md D-2, same 5 mm): covered length = length of the UNION of our pieces' intervals (bbox, along the source wall's long axis) inside the source wall rect; expected uncovered = length of the UNION of the source openings' intervals (door interval shrunk by 0.076 at each end, D-2). Union instead of sum because stacked windows share one plan interval and mitre triangles overlap the long pieces' bboxes. For pieces that never overlap (Level 1) union = sum.
    • rosetta_dx.js config adds wall.polygon_footprint: true and opening.gap_min 0.3 / gap_max 5 (SANDBOX, same values as rosetta_dx_types.js). Expected: R1b-u Level 1 17/17, Level 2 17/17; R1a still 0 stray (polygon pieces' bboxes inside a source wall); R1c 0 unexplained.
    • R6-shell (rosetta_dx_shell.js): every piece with height_source: elevation has the z range of the source wall containing it (10 mm), asserted; slab_above pieces: count equal / not equal reported, each mismatch listed (INFO, a convention is not asserted).

    3. Shared: rectilinear shell solid¶

    • SH-M prismRect(outline, holes, z0, z1): outline and holes rectilinear (every edge axis-aligned within 1e-9 after rounding to 6 dp), holes inside the outline and disjoint. Grid = all distinct x and y of outline and holes; a cell is solid when its centre is inside the outline and inside no hole. Top and bottom = two triangles per solid cell; sides = one quad (two triangles) per cell edge between a solid cell and a non-solid cell or the outside, oriented outward. Result is one closed, outward mesh (each directed edge once, reverse once). Non-rectilinear input → GAP:shell_not_rectilinear (no mesh). Deterministic: cells in (y, x) order. Tests: SM1 rectangle 2x3, z 0..0.5 → volume 3.0, watertight · SM2 rectangle with a 1x1 hole → volume (6-1) x 0.5, watertight, the hole has inner side faces · SM3 L-shape (area 12) → 12 x thickness · SM4 diagonal outline → gap, no mesh · proves (all): a slab mesh that is open, inside out, fills holes or invents area.

    4. Floor slabs¶

    4.1 S-O outline (convention on drawn walls)¶

    • S-O Only for a storey whose footprint walls form a rectangular envelope E (bbox of all emitted wall pieces of the plan, rect or polygon). For each face F of E: the exterior pieces of F are pieces whose rect touches F's plane (snap_tol) and whose long axis is parallel to F (squares and polygon corner triangles excluded). Their inner edges (the rect side opposite F) must all be equal within snap_tol → inner line of F; zero pieces → GAP:slab_no_exterior_wall (face named); unequal → GAP:slab_inner_face_conflict (values listed). Outline = rectangle of the four inner lines. Convention, stated: "the slab spans between the inner faces of the exterior walls" (the source model's convention, slab-between-walls); NOT read from a slab entity (none exists in the set). outline_source: 'exterior_wall_inner_faces', members = handles used.
    • Not drawn, therefore not built: splits of the slab under party walls, stair voids, exterior porch slabs, finish-floor layers. The pipeline cannot see them; the witness lists the area they account for (§4.4).

    4.2 S-Z top and underside (from elevation-derived wall heights)¶

    • S-Z1 top T = level + base of the storey's exterior pieces with height_source: 'elevation'; all must agree within elev_tol, else GAP:slab_top_conflict; none → GAP:slab_no_top.
    • S-Z2 underside U = the common top level_below + base + height of the pieces of the storey BELOW that have height_source: 'elevation' and end strictly below T (by more than elev_tol). All must agree within elev_tol, else GAP:slab_underside_conflict (values listed); none (no storey below in the set, or no lower piece ends below T) → GAP:slab_no_underside. Convention, stated: a lower wall seen in an elevation that stops below the next floor stops at that floor's underside.
    • S-Z3 thickness = T - U > 0, else GAP:slab_bad_thickness. No thickness → the slab op is emitted with thickness: null and NOT meshed (GAP:slab_no_underside carried). Never a default thickness. Expected before the run: Level 1 T = 0 (GF exterior rects start at 0), U: no storey below in the set → GAP:slab_no_underside (the foundation is seen only as elevation rects -1250..0, which end AT T, not below; and is not a plan). Level 2 T = 3.1, U = 2.795 (Level-1 interior walls seen in FRONT/REAR/LEFT/RIGHT stop at 2795) → 0.305 m. Tests: SZ1 hand: lower pieces end at 2.795 (two) and 3.1 (one, ends at T: excluded) → U 2.795 · SZ2 lower tops 2.795 and 2.6 → conflict gap, no slab thickness · SZ3 no lower storey → slab_no_underside, op has thickness null, not meshed · SZ4 T disagreement → slab_top_conflict · SO1 4-face envelope → inner rectangle (hand) · SO2 inner edges differ on one face → conflict gap · SO3 face without an along-face piece → gap · proves (all): invented thickness, a lower wall that reaches the floor treated as an underside, or a slab outline guessed where walls disagree.

    4.3 Slab op and mesh¶

    DXF_SLAB params: outline, holes: [], top, bottom, thickness, outline_source, z_source ({top: handles, underside: handles}), storey. Meshed with SH-M from bottom to top. GUID = hash(run ids of the storey | 'slab').

    4.4 Witness (rosetta_dx_shell.js), per storey¶

    Exact area classification on a compressed grid (all x, y of our outline, the source slabs' projected top triangles, the source walls' rtree rects, the source stair/railing rects of the storey band): every cell centre is classified once. - SL-a outline: each edge of our outline equals the corresponding extreme of the union of the storey's structural source slabs (not "Finish Floor", not porch slabs lying outside E) within 1 mm. Asserted. - SL-b precision: area in ours and not in a source structural slab = (under a source wall of this or the next storey: convention slab-under-wall) + (inside a source IfcStairFlight/IfcRailing rect: stair void not drawn) + OTHER. Asserted OTHER ≤ 0.01 m². - SL-c recall: area in source structural slabs inside E and not in ours = OTHER ≤ 0.01 m² (asserted); slabs outside E (porch) reported as not drawn. - SL-d z: our top and bottom vs the source structural slab z range of that storey (10 mm), asserted where we have a thickness; Level 1 reported as GAP (expected slab_no_underside).

    5. Roof¶

    5.1 R-O outline¶

    • R-O1 roof plan check: the ROOF plan (layer type roof in its layer map) must hold exactly one closed outline; it must equal the OUTER envelope E of the top storey's walls within snap_tol (consistency: the roof covers that storey). Else GAP:roof_outline_mismatch (both rects listed), no roof.
    • R-O2 slab outline = S-O applied to the top storey's pieces (the roof slab spans between the inner faces of the top storey's exterior walls, the same convention as floors). outline_source: 'top_storey_inner_faces', plus the A-ROOF handle.

    5.2 R-Z bottom and top¶

    • R-Z1 bottom B = common top (level + base + height) of the top storey's exterior pieces with height_source: 'elevation' (all agree within elev_tol, else GAP:roof_bottom_conflict; none → GAP:roof_no_bottom).
    • R-Z2 top = the @ROOF marking (§5.3) of the marked elevations: every elevation that carries it must agree within elev_tol (else GAP:roof_top_conflict), and each value must coincide with a drawn horizontal line of type levelline in that elevation (via the @Z calibration, within elev_tol), else GAP:roof_top_not_drawn. No @ROOF anywhere → GAP:roof_no_top, roof not meshed.
    • Expected before the run: B 6.0 (Level-2 exterior rects end at 6000), top 6.5 (ROOF LEVEL +6.500 line). The source roof top is 6.457: the witness is EXPECTED TO FAIL on the roof top by 43 mm (the drawing's roof level marker disagrees with the model; reported as a finding, not tuned away).

    5.3 Marking @ROOF (dxf2marks.js, one new key)¶

    • @ROOF=<metres> (ELEV view, single value, number; malformed/conflict per §24 rules): "the top of the roof structure is at this absolute height". The marker author takes it from the drawing's roof level line; the reader never parses level text (SPEC.md V5). For the Duplex the marking step of rosetta_dx_shell.js reads the A-ANNO-LEVL text ROOF LEVEL +6.500 in each elevation and writes @ROOF=6.5 into a COPY (out/marked_shell/); it refuses (no marker) when an elevation has zero or more than one such text. Test MK-R (test_shell.js): parse @ROOF=6.5 → desc.roof 6.5; @ROOF=abc → MARK:malformed; two different values → MARK:conflict · proves: a roof height read from a bad or contradictory marking.

    5.4 R-H roof openings¶

    • R-H Each closed polyline of type glazing in the ROOF plan that lies inside the roof outline is a roof hole equal to that rectangle (the drawn skylight unit). Not rectangular → GAP:roof_hole_not_rect; outside or crossing the outline → GAP:roof_hole_outside. Stated limit: the drawing shows the skylight unit, not the structural opening; the hole is the unit outline.
    • Witness RH: hole centre vs source roof-slab hole centre ≤ 10 mm (asserted), our hole contains the source hole (asserted), the size excess per side reported.

    5.5 Witness (roof)¶

    RF-a outline edges vs source roof slab 1121 extremes (1 mm, asserted) · RF-b area classification as §4.4 (holes compared as RH) · RF-c bottom vs source 6.0 (10 mm, asserted) · RF-d top vs source 6.457 (10 mm, asserted; expected FAIL, see §5.2). Not built: parapet walls (source storey Roof, 6.0..6.609: seen only in elevations, no plan), foundation walls (seen only in elevations, no plan), skylight fills (§7.6).

    6. Openings cut into walls (drawn gaps bridged)¶

    The Duplex plans split every wall at its openings (drawn gaps). A wall with a window is therefore missing the wall below the sill and above the head. The cut is made by building what the elevation shows around the void, never by guessing it. - OP-1 Strip: for an opening O (door with a height, or window with sill/height) its host piece H (host_wall) gives the strip: H's cross range (rect side across the axis) and axis. Pieces of the same storey with the same orientation and the same cross range (within snap_tol) are the strip's pieces, sorted along the axis. - OP-2 Gap: O's span centre c along the axis (window: bbox centre; door: midpoint of hinge and the swing end point nearer the host axis, SPEC.md M-c) must lie strictly between two consecutive strip pieces A (before) and B (after): G = [A.end, B.start]. c inside a piece → GAP:opening_inside_piece (needs a true cut; none expected); no piece on one side → GAP:opening_gap_unbounded. - OP-3 Height: A and B must have the same level+base and top within elev_tol (else GAP:gap_height_conflict) and a height (else GAP:no_height). Every opening of G must lie inside [zb, zt] (else GAP:opening_outside_wall). - OP-4 Infill: G x strip x ([zb, zt] minus the union of the z intervals of all openings whose centre is in G) → one box per remaining interval (sill, between stacked windows, lintel), class IfcWall, infill: true, infill_of: [A.handle, B.handle], openings: [handles]. The void is G x opening z range: its width is the DRAWN gap, not the arc radius. - OP-5 Gaps without an opening (an interior door with no height, an export-defect door arc, see SPEC.md §21) stay full-height slots and are listed NOTE:gap_without_opening with the gap interval. Tests: OP1 window 1.0 wide, sill 0.9, height 1.2 in a 1.0 gap between two 3 m pieces → 2 infill boxes (0..0.9, 2.1..3.0), total volume = gap x t x (3-1.2) · OP2 three stacked windows → 4 boxes (sill, two mullion strips, lintel), hand z · OP3 door (sill 0) → lintel only · OP4 A and B with different tops → gap_height_conflict, no infill · OP5 opening centre inside a piece → opening_inside_piece · OP6 gap with no opening → NOTE, no infill · OP7 order independence (20 permutations of ops) · proves: voids not cut, wall above/below a window missing, wall built across a door, invented heights, order dependence. Witness OV (rosetta_dx_shell.js), for each source IfcDoor/IfcWindow hosted (rel_fills_host) in an IfcWall of Level 1/2: sample our wall solids (pieces, polygon prisms, infill) at the opening's plan centre: (1) z = centre, z0+20 mm, z1-20 mm → in NO wall solid (void cut); (2) z1+20 mm when the host source wall top is more than 40 mm above z1 → INSIDE a wall solid (wall above present); (3) z0-20 mm when z0 is more than 40 mm above the host wall base → INSIDE (wall below present). Status per opening: ok / explained (a logged gap at that opening: door without height, door_below_min_width) / FAIL. Asserted: FAIL = 0; counts reported.

    7. Fills from the LOD400 component library (no fallback)¶

    User directive (~/bim-compiler/prompts/RESUME_MODELLER_LOD400_REAL_GEOMETRY.md §LOD400-ENVELOPE): a bound product without real geometry is a HARD FAIL plus a GAP; never a box. - GEO-1 Product → type name. From the bound ad_opening_family row: size key = first NNN x NNN pair of its description (digits only; same pairKey as rosetta_dx_types R-T2); family token = the description text before that pair, trimmed. Candidates = distinct ad_geometry_map.element_ref of the same ifc_class whose size key equals it; if some candidates' family part (text before the first :) equals the token, keep only those.
